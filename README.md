# Library Catalogue

A responsive web-based library catalogue that allows users to explore a collection of books by title, author, and category.

## Project Overview

The Library Catalogue is a frontend web application developed as part of the IS Project 2026.

The application provides a simple and responsive interface for browsing books and discovering information about the library's collection.

## Features

- Responsive library homepage
- Book catalogue page
- Book dataset stored in JavaScript
- Book categories
- Search and filtering interface
- Responsive layout for desktop, tablet, and mobile devices
- About page
- Book details interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
