\# Library Catalogue – Submission Report



\## 1. Project Overview



The Library Catalogue is a responsive web-based library catalogue developed as part of the IS Project 2026. The application allows users to browse books, search and filter the catalogue, view book details, and make book reservations.



The project focuses on providing a simple, accessible, and responsive interface that works across desktop, tablet, and mobile devices.



\## 2. Project Objectives



The main objectives of the project were to:



\* Develop a functional web-based library catalogue.

\* Allow users to browse books by category.

\* Provide search and filtering functionality.

\* Display detailed information about individual books.

\* Provide a book reservation interface.

\* Ensure the interface is responsive on different screen sizes.

\* Improve accessibility and keyboard navigation.

\* Deploy the application using GitHub Pages.

\## 4. Main Features



\### Homepage



The homepage introduces the Library Catalogue and provides access to the main sections of the application. It also displays book categories and featured books.



\### Book Catalogue



The catalogue page allows users to browse the available books.



Users can:



\* Search for books.

\* Filter books by category.

\* View book information.

\* Open the book details interface.



\### Book Categories



Books are organised into different categories, including:



\* Fiction

\* Science

\* Technology

\* History



\### Book Details



Users can open the book details interface to view information about a selected book, including:



\* Book title

\* Author

\* Category

\* Description



\### Book Reservations



The application provides a reservation form where users can enter:



\* Full name

\* Email address

\* Reservation date



\### About Page



The About page provides information about the purpose of the Library Catalogue and provides navigation to the catalogue.



\## 5. Responsive Design



The application includes responsive CSS rules that allow the interface to adapt to different screen sizes.



The application supports:



\* Desktop screens

\* Tablet screens

\* Mobile devices

\* Small mobile screens



The catalogue grid, navigation, forms, modal interface, and other components adjust appropriately for smaller screens.



\## 6. Accessibility Improvements



Accessibility improvements were implemented to make the application easier to navigate using keyboards and assistive technologies.



These improvements include:



\* Skip-to-content links.

\* Accessible navigation labels.

\* Semantic main content identifiers.

\* Visible keyboard focus indicators.

\* Decorative icons hidden from screen readers using `aria-hidden`.

\* Accessible modal attributes.

\* An accessible modal close button.

\* Live status announcements for reservation messages.

\* Escape-key support for closing the book details modal.

\* Consistent font inheritance for form controls.
